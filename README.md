### Webbed Words is a web application for generating custom crossword-style word boards from your own word lists. Built with Angular.

There aren't any formal contribution guidelines. If you'd like to contribute, just open a pull request with a brief description of your changes, or open an issue if you've found a bug or have a feature request. Thanks for checking out the repo!
